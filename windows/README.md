# Murmur for Windows

Push-to-talk dictation for Windows 10/11 (x64): hold a key, speak, release, and the cleaned text is pasted where
you are typing. Everything runs locally (no cloud).

## Install

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1          # add -Startup to start at login, -NoLaunch to not start it
```

`scripts/setup.ps1` is non-interactive and idempotent. It downloads the newest `win-v*` release zip to
`%LOCALAPPDATA%\Murmur`, then the speech model (NVIDIA Parakeet TDT 0.6B v2, int8 ONNX) and the cleanup model
(Qwen3-4B-Instruct-2507 Q4_K_M GGUF) into `%LOCALAPPDATA%\Murmur\models` with resume and size/SHA-256 checks, and
creates a Start-menu shortcut. Things only a human can do: allow desktop apps to use the microphone (Settings >
Privacy & security > Microphone) and, if SmartScreen appears, click "More info" > "Run anyway".

## Use

* Hold **Right Ctrl** (default), speak, release. **Esc** cancels. Double-tap = hands-free (tap again to stop).
  Pressing another key while a modifier key is held cancels silently (it was a shortcut).
* Tray icon > *Set push-to-talk key...*: Right Ctrl, Ctrl+Win, Right Alt or F1-F12.
* Vocabulary learning: after a paste, if you correct a word, a small pop-up offers *Add*, *Dismiss* or *Don't suggest*.
  Password fields are never read. Tray icon > *Suggest vocabulary from my edits* turns it off.
* Data: `%APPDATA%\Murmur` (`dictionary.json` same schema as the macOS app, `history.jsonl`, `config.json`, `debug.log`).

## Architecture (Rust workspace)

| crate | what |
| --- | --- |
| `murmur-core` | Pure Rust, tested on Linux/macOS/Windows: deterministic cleanup + LLM gate and drift guard, dictionary with fuzzy learned replacements, vocabulary-diff candidate rules, keystroke-replay model. Ported from the Swift sources and checked against `shared/test-vectors/*.json` (generated by the macOS app). |
| `murmur-win` | Tray app: `WH_KEYBOARD_LL` hook, cpal/WASAPI capture (16 kHz mono), sherpa-onnx Parakeet (CPU), `llama-server.exe` (llama.cpp CPU) for gated LLM cleanup with a 0.9 s budget and deterministic fallback, clipboard + `SendInput` Ctrl+V with clipboard restore, no-activate overlay, UI Automation vocabulary learner. |

The spell checker the macOS rules use (`NSSpellChecker`) is replaced by a bundled English word list
(`murmur-core/data/words.txt.gz`) with a few heuristics; the shared vectors pass.

Debug switches: `murmur.exe --transcribe file.wav`, `--test-audio file.wav` (feed a WAV instead of the microphone),
`--ptt right-ctrl|ctrl+win|right-alt|f9`, `--llm-selftest`, `--uia-read-focused`.
Environment: `MURMUR_APPDATA`, `MURMUR_MODELS_DIR`, `MURMUR_LOG_STDERR=1`.

## CI

`.github/workflows/windows.yml` (windows-latest): core tests, release build and packaging, `setup.ps1` against the zip
built in the same run, headless transcription of a System.Speech WAV, a Notepad end-to-end UI test, an LLM cleanup
test through `llama-server.exe`. A `win-v*` tag publishes the zip as a GitHub Release and re-runs `setup.ps1` against it.
